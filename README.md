# SIM-001 流水线看板

本仓库是团队共享的 **SIM-001** 看板（`index.html` + `progress.json`）。

## GitHub Pages

仓库所有者先开启 Pages：

**Settings → Pages → Deploy from a branch → `main` → `/`（root）**

开启后同事打开：

https://laodaohedaxia.github.io/pft-pipeline-board/

## 权限

- **读**：公开即可浏览看板
- **写**：需要 fine-grained PAT，仅对本仓库开 **Contents: Write**，粘贴到看板右上角密码框
- **切勿**把 Token 提交进仓库
